# MOD Manager 2.0

新版正式标志、即时主题切换，以及更轻快的日常 MOD 管理。

## 下载

- [Windows x64 独立 EXE](https://github.com/8Cola/MOD-Manager/releases/download/v2.0.0/MOD-Manager.exe)
- [完整项目源码](https://github.com/8Cola/MOD-Manager/releases/download/v2.0.0/MOD-Manager-2.0.0-source.zip)
- 同页提供 SHA256SUMS.txt、MIT 许可证和第三方组件声明。

## 主要更新

- **全新正式 Logo**：蓝色玻璃游戏方块，以 SVG 代码重绘。桌面图标、界面左上角和“关于”页统一；EXE 内嵌多尺寸资源已逐帧核对。
- **深色启动不再闪白**：首屏按照保存的主题显示，避免先出现浅色再切换。
- **主题切换立即响应**：保存放到后台，连续切换以最后一次选择为准；保存失败会提示并恢复已保存外观。
- **减少无用等待**：合并重复刷新，健康监控不再每 3 秒递归遍历所有文件，保留监控异常时的检查和定时兜底。
- **局部更新更轻快**：打开文件夹不扫描全库，保存备注和封面只核对对应 MOD；当前目录刷新只处理所选目录。
- **大量 MOD 更顺畅**：缓存搜索索引与游戏统计，复用列表项，封面按需加载并异步解码。

## 升级说明

退出旧程序后运行新版，无需安装。原数据位置仍为 `%APPDATA%\com.modmanager.desktop`，可继续使用已有游戏、备注、分组和图片。建议升级前在设置中导出管理器备份；备份不包含 MOD 文件本体。

仍需 Windows 10/11 x64 和 WebView2。启停保持原位追加 `.disabled`；是否停止加载取决于具体游戏或加载器。文件操作前检查、同名保护和失败恢复均保留。禁用文件夹中新加入的文件保持原样，并显示状态不一致。
