# MOD 封面操作与原图查看

MOD 详情封面下方常驻三个紧凑按钮：添加／更换封面、粘贴图片、移除图片。未设置封面时移除按钮禁用。点击方形封面查看裁切前原图，支持适应窗口、原始尺寸及滚动查看。

新导入的文件图片和剪贴板图片，在确认裁切时同时保存 512×512 封面和裁切前原图。原图保存在应用数据目录，包含于配置备份，不依赖最初图片文件的位置。旧版封面没有保存原图，需要重新导入；程序不会将裁切图冒充原图。移除图片清除两项关联，不删除用户源图片，不提交尚未保存的备注。

验证结果（2026-10-11）：

- Rust 后端测试：94 项全部通过，包含原图字节保留、重启恢复、备份导入恢复、移除关联及无效原图拒绝。
- `scripts/qa-original-cover.cjs`：实际 Windows WebView 程序 6 组检查通过，使用独立测试目录。1024×512 原图与 512×512 封面分别核对，原图字节相同。
- `scripts/qa-clipboard.cjs`：9 组检查通过，包含真实 Windows 剪贴板、常驻粘贴按钮、裁切取消和文本粘贴；测试后恢复系统剪贴板。
- `scripts/qa-manual-notes.cjs`：7 组检查通过，备注仍需手动保存；移除封面不触发备注保存。
- 前端类型检查及生产构建、Windows Release 构建通过。
