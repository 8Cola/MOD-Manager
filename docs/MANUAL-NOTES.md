# MOD 信息手动保存与图片移除

2026-10-11：取代旧版的备注自动保存行为。

- 备注输入仅修改当前草稿，点击“保存信息”才将备注和管理选项写入。
- 关闭详情或程序时，存在未保存的修改会提示保存、放弃或继续编辑。
- 图片的更换或移除不会顺带保存未提交的备注。
- 详情图片菜单新增“移除图片”，封面旁提供明确的“移除图片”按钮；无图片时该按钮禁用。
- 分组等会关闭当前记录的操作先处理未保存草稿，保存后使用最新持久化备注。
